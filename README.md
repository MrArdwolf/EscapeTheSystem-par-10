# ESCAPE THE SYSTEM

## Beskrivning

Ett escape room-spel byggt i React och TypeScript. Spelaren går igenom olika rum i en övergiven forskningsanläggning, samlar items och löser pussel för att kunna fly.

### Hur man startar projektet

Klona projektet: ``git clone https://github.com/MrArdwolf/EscapeTheSystem-par-10.git``

Installera beroenden: ``npm install``

Starta utvecklingsservern: ``npm run dev``

Öppna spelet i webbläsaren: ``http://localhost:5173``

### Implementerade krav

#### G:

- Routing mellan olika rum med React Router   
- Startsida med introduktion   
- Navigation till med länkar (Link) till spelets olika rum   
- Inventory där spelaren kan plocka upp och använda items   
- Lösningslogik för varje rum (unsolved -> solved)   
- Användning av JSON-data för rum och items   


#### VG:

- Vinstskärm som visas när sista rummet är löst   
- Hint-system med knappar för visning av ledtrådar   
- Route (*) för att fånga okända paths   
- Komponentbaserad struktur   


### Tekniker

- TypeScript
